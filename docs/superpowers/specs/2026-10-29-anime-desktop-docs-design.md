# 桌面与教程站二次元风格设计稿

日期：2026-10-29。用户已确认范围：桌面应用和教程网页都改。建议视觉方向为「晴空樱花」，本文已获用户确认，后续补充已并入；实施与验证状态见计划及工作记录。

## 目标与候选方向

推荐「晴空樱花」：以动漫天空插画、浅蓝背景、樱粉强调和深蓝文字构成清爽工作台，插画作为局部氛围，表单、状态、表格保持清晰。另有「夜樱深色」（更强夜间氛围）和「轻量动漫」（只调整配色与横幅）两种备选；用户已选择推荐方向。

保留 React/Tauri 与 Astro/Starlight 技术栈、七页导航和现有操作流程，不新增组件框架、字体包或动效依赖。重构任务继续保留，不能将这次美化当作此前三批结构统一已全部完成。

## 共用视觉与素材

- 主色使用晴空蓝与樱粉，正文使用深蓝灰；危险、成功、警告仍使用原语义颜色，不能用粉色掩盖失败。
- 以已有 CSS 变量管理颜色与玻璃表面，减少新增硬编码颜色。保留明暗主题、键盘焦点、缩放和 reduced-motion 支持。
- 按用户后续确认使用原创 AI 动漫风景，包含晴空、晚霞、星夜，不直接照搬具体作品；两边本地打包，不依赖远端加载，主界面不加入署名。
- 生成提示、工具及具体文件 SHA256 记录在 docs/ART_ASSETS.md；已放弃的外部素材不再保留。
- 桌面与网页共用同一幅主视觉和色彩语言；网页的素材路径通过 Astro base 处理，不硬编码根路径。

## 桌面应用

1. 保留已有雾白、深夜、樱粉设置及用户保存的选择；升级樱粉的视觉表现，并在皮肤面板提供明确的动漫风景预设。首次打开的视觉与已有用户偏好迁移，在实施计划中明确，不强制覆盖存量壁纸。
2. 侧栏品牌区增加轻量云朵/樱花图形，选中态、快速发布按钮和底部信息统一层级，保持现有导航、版本提示和帮助入口。
3. 发布页加入有实际用途的风景欢迎区与清楚的上传入口，状态信息、目标选择、任务和最近资源保持可见；装饰不能替代错误提示或前置条件。
4. 资源、图库、云端等页面通过统一表面、标题和控件样式接入，不逐页增加整屏人物背景；桌面数据操作、凭据、更新与云端权限逻辑保持原样。
5. 壁纸预设使用受控资源标识，不把任意 file/data/javascript 路径放进 CSS。原有用户 http/https 壁纸输入保持兼容。本机导入的图片独立保存为有界 JPEG，仅通过本地标识读取，不接受任意 data/file 路径；提供清除与恢复，导入错误不能影响业务或旧设置。
