# 桌面界面约定

以实际任务为入口；保持现有 React/Tauri 技术栈、主题和业务接口。

## 功能归属

| 主入口 | 内容 | 就近操作 |
| --- | --- | --- |
| 上传 | 本地图片、剪贴板、图片 URL | 目标选择、当前输出格式、最近活动 |
| 上传记录 | 本机记录及其发布结果 | 单条复制、分享、重试；批量操作紧邻列表 |
| 云端配置 | 存储连接、存储组、处理策略 | 测试、编辑、默认目标；配置帮助指向对应教程 |
| 云端文件 | 远端文件与目录 | 当前目录筛选、文件操作和批量操作 |
| 插件 | 已安装、插件库、AI、执行记录 | 按分类显示配置，敏感能力沿用授权流程 |
| 任务 | 队列、进度及失败结果 | 取消、重试紧邻对应任务 |
| 设置 | 上传与复制、快捷集成、接口与安全、数据迁移、后台检查、关于与诊断 | 分类搜索；低频项放入对应分类 |

快捷上传复用同一上传对话框；上传页降低其视觉权重。空状态允许提供配置引导；有引导时不再展示另一处无目标配置卡。同一区域的“查看全部”只保留一处，随当前记录/任务分类切换。必要的上下文快捷入口可以保留，不能以去重为由让用户退出详情才能操作。

不把未知归属的功能一律塞入设置。先按影响范围选择页面、区块或单条对象，再按频次决定是否常驻。危险操作仍需原有确认与执行中保护。

## 视觉与响应式

- 共享尺度定义在 `apps/desktop/src/styles/design-tokens.css`：4、8、12、16、24、32px；布局使用 Flex/Grid，避免固定内容宽度。
- 控件圆角8px、主要面板16px；说明12px、正文14px、区块16px、页标题24px；窄窗标题20px，每页保持四档层级。
- 基础控件高度40px，窄窗触控目标至少44px。桌面侧栏保留文字，宽度不超过700px时使用顶部页面选择器。
- 正文、辅助文字与强调色取现有主题变量。错误、警告、成功保留语义颜色，不能为统一配色而删除状态区别。
- 壁纸只在应用外壳渲染一次，阅读区域使用局部透明底色与 backdrop-filter；文字本身不模糊。不添加重复背景贴图或覆盖整个工作区的大背板。
- 不在布局祖先添加 filter、transform 或包含块，以免固定对话框被裁切；弹窗沿用实底和焦点保护。

检查须区分浏览器响应式、原生窗口/DPI与安装包。浏览器预览成功不等于真实云端或升级保真通过。
