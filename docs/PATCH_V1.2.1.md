# v1.2.1 插件开关交互

本次把“方案”从主导航移除，主导航只保留一个“插件”入口。

## 交互

- 已安装插件放在页面最上方，每个插件都有独立开关。
- 支持“全部开启 / 全部关闭”。
- 插件市场与 AI 配置折叠到次级区域，避免干扰日常上传。
- 旧的 Workflow 数据结构仍保留为内部图片处理与 Typora 兼容层，但不再作为主界面概念。

## 执行语义

开启插件后，Publisher 在图片远端上传成功后自动调用插件。插件执行失败不会回滚已经成功上传的图片，而是在任务备注中记录。关闭插件后，后续上传不会调用它。

Typora CLI 读取与桌面应用相同的插件表，因此开关对 Typora 直传同样生效。
