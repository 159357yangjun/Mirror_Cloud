## A. 可追溯的应用架构事实

- `apps/desktop/src/App.tsx` 根据 `useAppStore.page` 条件渲染七个页面，挂全局 `UploadDialog`、`ToastViewport`、`ConfirmDialog`；目前不是长驻的 7 页面缓存。
- `apps/desktop/src/components/AppShell.tsx` 固定提供七个入口：发布 → 资源 → 云端 → 图库 → 插件 → 任务 → 设置，另有快速发布、主题、新手教程。导航带 `aria-current`、图标的可访问名称和焦点样式。
- `apps/desktop/src/store/useAppStore.ts` 储存当前页面及上传弹窗；各页面自己持有部分搜索、当前目录及选择状态。
- `project.taskui.json` 当前覆盖 T1 首次发布、T2 复制链接、T3 失败恢复及其中 4 个 screen；它**不是**十条任务、七页 G1 的完整清单。
- `SettingsPage.tsx` 约 1657 行，混合输出、Typora、本地 API、快捷键、迁移、更新与诊断。未来拆分前必须冻结功能合同与迁移路径。
- **Asset（已发布资源索引）与 StorageEntry（实际云端文件）有不同事实来源**：跨页仅以已确认的远端路径/存储 ID 关联，禁止按文件名猜关联。
- 现有发行门禁与 PR #40 的 R2 受保护真实测试均不在 UI-00 范围。

## C. 核心对象与信息边界（必须冻结后才能并行改页面）

| 对象 | 事实来源 | 显示状态 | 不可推断 |
|---|---|---|---|
| Storage / StorageGroup | 实际配置、Provider 连接与角色 | 已配置、检测未做/成功/失败、目标选择 | 连接成功 ≠ 公开/私有访问权限已确认 |
| Asset | 镜云发布资源索引 | 发布请求、已上传、部分副本失败、结果未知 | Asset 存在 ≠ 每个远端对象均可匿名读取 |
| Deployment | Asset 对应不同存储的发布副本 | 可单独确认/修复/标记异常 | 一个副本成功 ≠ 所有副本成功 |
| StorageEntry | 真实远端对象/目录 | 存储 ID、远端路径、对象类型、操作结果 | 文件同名 ≠ 与某个 Asset 是同一个对象 |
| Task | Rust 后台任务及事件 | 排队/运行/成功/部分/失败/未知 | 进度到100% ≠ 远端操作已确认；未知 ≠ 可直接重试 |
| Plugin / Permission | 插件清单、已授权能力与执行记录 | 安装/启用/授权/撤回/失败 | 插件启用 ≠ 可以无条件读取 Secret / 外发数据 |
| GuideContext | **设计目标，不是现有实际业务接口** | 帮助主题、来源屏幕/对象 ID/返回定位 | 不保存密钥、原始错误和签名 URL |

## D. UI-00 拟验证的十项真实用户任务

以下任务及频率是**设计假设**，需要新手/有经验用户的真实走查修订，不得填成已完成测试。

| ID | 用户目标与最短路径 | 正常完成证据 | 必测失败/取消路径 | 优先级 |
|---|---|---|---|---|
| T1 | 第一次：发布→云端→发布→任务→资源 | 存储实际生效、任务结束、资源有可核对副本 | 没云端、桶错误、权限拒绝、上传结果未知 | P0 |
| T2 | 搜索并分享：资源→对象→复制或生成限时链接 | 公网/私有链接类型正确，有复制反馈 | 无公开链接、签名失败、分享过期 | P0 |
| T3 | 失败恢复：任务→错误→云端/资源修复→任务 | 确认失败项恢复且不重发已成功对象 | 部分成功、重复提交、网络不确定 | P0 |
| T4 | 图库远端维护：图库→目录→对象→下载/移动/删除 | 仅选定的真实 StorageEntry 变化 | 删除取消零调用、跨桶选择、冲突与部分完成 | P1 |
| T5 | 配置/切换 Provider 与发布目标：云端→返回发布 | 目标 ID 生效、未验证能力明确 | API 与公共 URL 混淆、存储组副本角色错误 | P0 |
| T6 | 安装插件/启用 AI：插件→权限→配置→记录 | 最小权限获得批准、执行记录正确 | 过宽权限、撤权、外发或密钥访问风险 | P1 |
| T7 | 调整输出与 Typora：设置→发布→复制验证 | Markdown/链接输出符合实际选择 | 手动命令错误、集成配置未生效 | P1 |
| T8 | 迁移恢复：设置→清单预览→映射→确认激活 | 数据与映射能核对，原数据未误覆盖 | 映射冲突、半完成、中途取消与恢复 | P0高风险 |
| T9 | 更新检查/安装：设置→检查→下载→安装→重启 | 版本确已升级、可回滚 | 下载误认为安装、安装失败/回退 | P0发布门 |
| T10 | 情境帮助：任意错误→打开对应教程→返回原位 | 原对象/字段/草稿与焦点恢复 | 教程中断、入口失效、离线无网络 | P0体验 |

## E. 需要在 G1 决定的信息架构与页面草图任务

整体导航**暂不由七个减成六个**；先固定七入口和语义，用户任务测试证实必要后才提修改。G1 要交付的七页结构草图：

1. 发布：对象输入工作区 / 右侧目标配置 / 下方最近活动（验证已实现首批）。
2. 资源：左筛选和搜索 / 中央索引网格或表格 / 选中对象详情与副本状态 / 就地分享。
3. 云端：连接与健康列表 / 选择目标 / Provider 配置向导 / 按权限级别执行诊断。
4. 图库：存储选择与面包屑 / 目录及真实远端对象 / 对象详情 / 危险批量动作单独确认。
5. 任务：状态过滤 / 任务队列 / 选中任务的证据与下一步 / 安全恢复操作。
6. 插件：已安装与授权 / 执行记录 / 可选商店 / AI 折叠区。
7. 设置：组内导航 / 当前组编辑区 / 专用预览、迁移确认和更新状态机。

必须有**全局统一的四段式错误说明**：已确认事实、可能原因、建议修复、尚未验证；详细调试信息不可含 Secret、Token、签名 URL。错误就地显示，Toast 只用于不遮挡的瞬时反馈。

## F. 风险优先级与失败反例

| 编号 | 风险或断点 | 已有证据 / 未决 | 必须做的安全验收 |
|---|---|---|---|
| R-01 | 原始 Provider 错误可能穿过前端提示 | 源码中可见多个 `String(error)` 或 `task.error` 直显；真实敏感输入输出**未证实** | 在 mock 错误中注入假 Secret/签名，检查 DOM、Toast、日志、Artifact 无泄漏；后端安全错误码优先 |
| R-02 | R2“测试连接”带临时远端写入 | 已由旧 Rust 探针审查和 PR #40 安全记录证实 | L0本地/ L1真只读/ L2明确写入分离，取消调用数=0 |
| R-03 | 远端对象与发布资产混合 | 两页 API 语义不同，跨页关联必须审核 | 无真实 storageId+remotePath 时不给“同一对象”断言 |
| R-04 | 条件挂载造成筛选、目录丢失 | `App.tsx` 源码证实条件挂载；是否影响具体任务待回放 | 切页/错误/教程返回保存安全上下文，跨桶清理危险选择 |
| R-05 | 任务不确定时重复重试 | 任务重试能力存在，但 safe/unknown 逻辑待完整审计 | 未确认状态不得默认再次提交，已有成功副本不能重写 |
| R-06 | 设置迁移与升级状态机被界面重构破坏 | Settings 巨型组件与多阶段状态可证实 | 快照/迁移/回滚双向证据，禁止以“UI 成功”替代原生事实 |
| R-07 | 插件授权不透明及泄密 | 权限种类与申请弹窗存在 | 默认最小权限、撤销状态确认、外发与 Secret 权限独立说明 |
| R-08 | 参考设计图的示例数据进入产品 | 参考图是概念 UI 而非真实状态源 | 不硬编码云已连接、成功率、进度、虚构资源和示例照片 |
