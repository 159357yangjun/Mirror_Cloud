# Milestones

## M0 — Skeleton ✅
工程工作区、领域模型、Storage Port、Desktop Shell、SQLite schema。

## M1 — First real upload ✅
Credential Store、SQLite Repository、R2/S3、文件选择/拖拽、Task Engine、公网 URL。

## M2 — Repository storage ✅
GitHub / Gitee、仓库浏览与删除、Raw URL、输出模板。

## M3 — Multi-cloud ✅
Storage Group、Primary / Mirror / Backup、多云发布、Partial 状态、跨云 Repair。

## M4 — Workflow & onboarding ✅
Rust 图片处理、Workflow、Recipe、Rename、默认方案、首次使用引导、Astro/Starlight 教程站。

## v1.0 — Production feature baseline ✅
- OSS / COS / WebDAV 正式 Provider。
- URL 批量发布。
- 剪贴板图片发布。
- 发布完成自动复制。
- 受控上传并发。
- 中断任务恢复为失败状态。
- Storage 安全删除约束。
- Provider 教程补齐。
- SQLite 查询索引与正式版文档。
- 版本统一到 1.0.0。

## v1.x 后续
只有通过真实需求验证后再加入：自动更新服务、Deep Link Recipe 导入、系统通知、更细粒度网络/并发偏好、完整备份恢复、CLI、更多 Provider。
