## 第一次发布，只需四步

<Steps>
1. 在桌面应用的**云端**添加一个连接，按向导测试并保存。
2. 将连接设为默认发布目标；需要多云副本时再配置多云组。
3. 在**发布**选择文件、剪贴板或图片 URL，核对列表后提交。
4. 在**资源**复制公开链接；私有资源使用限时分享，并在**图库**核对远端文件。
</Steps>

Token 和 Secret 只在桌面应用录入，写入系统凭据库；本网站不接收密钥。
