## 先在服务商准备

S3 Compatible不是一家具体图床：AWS S3、MinIO和其他兼容服务的控制台不同。先从服务商取得下表五项，不能照抄某一家的值用于另一家。

<Steps>

1. 创建或选中一个Bucket，记录**准确桶名与地域Region**。
2. 找服务商的“S3 API / 连接信息 / Endpoint”页面，复制HTTPS API地址。AWS以所在地域的S3服务地址为准；其他服务商使用其提供的值。
3. 创建用于这一个桶的访问凭据，取得 **Access Key ID / Secret Access Key**。权限需要能列举、读、写、删除对象；AWS策略通常涉及 ListBucket、GetObject、PutObject、DeleteObject，以及服务实际要求的桶地域/分段上传权限。
4. 决定是否公开发布。公开图片需要独立配置匿名可读的域名/CDN；私有目标保留访问控制。不要设置匿名可写。

</Steps>

## 在镜云逐项填写

打开 **云端 → 添加存储 → S3 Compatible**。

<ConfigurationFields provider="s3" />

点击 **测试并保存**，成功后在云端列表设为默认发布目标。连接测试需要相应远端读写/删除权限；不要拿只读账号测试上传。

<Aside type="note" title="地址与权限">
Endpoint用来操作存储；公开地址用来打开图片。二者可能不同。选“私有存储目标”不修改服务商桶策略。当前仅允许HTTPS或本机回环HTTP；普通局域网HTTP地址不能直接用于连接。
</Aside>

## 上传并确认结果

<Steps>

1. 发布一张测试图，在 **图库** 和服务商控制台核对同一个文件。
2. 公开目标：复制 **资源** 中的URL，用未登录浏览器直接打开。
3. 私有目标：验证匿名访问失败，应用内认证预览可用；如需限时分享，另验证服务商支持和到期行为。Typora/命令行需要公开URL，不能用私有目标完成该链路。

</Steps>

## 常见错误

| 现象 | 检查及处理 |
| --- | --- |
| 签名不匹配 / 403 | 密钥、Region、Endpoint是否匹配；检查本机时间与权限 |
| 找不到桶 | 桶名与地域一致吗？Endpoint是否多拼了一层桶名？ |
| 上传成功但无法列举/删除 | 凭据是否只授予写入，缺少列举、读取或删除权限 |
| 自建服务无法连接 | HTTPS证书、外网可达性；局域网HTTP不符合当前地址策略 |
| 图片URL要求登录 | 公开地址/策略未配置好，不要把登录后的管理链接当外链 |

参考：[AWS S3 权限与访问控制](https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-management.html)、[AWS S3 地域地址](https://docs.aws.amazon.com/general/latest/gr/s3.html)。MinIO等服务应同时核对其部署管理员提供的S3连接说明。
