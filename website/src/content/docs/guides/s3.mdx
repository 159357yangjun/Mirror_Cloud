## 准备什么

从服务商控制台取得 **Endpoint、Region、Bucket、Access Key ID、Secret Access Key**。凭据仅授予目标桶需要的列举、读取、写入与删除权限。Endpoint 与 Region 采用服务商给出的值，不要填写控制台网页地址。

## 在镜云填写

<Steps>
1. 进入 **云端 → 添加存储 → S3 Compatible**。
2. 填写显示名称、Endpoint、Region、Bucket 和密钥；资源目录可选，例如 `assets`。
3. 公开用途选择“公开发布”，填写真正可匿名访问图片的公开地址；私有用途选择“私有存储目标”，清空公开地址。
4. 点击 **测试并保存**，通过后设为默认目标，再发布一张图片。
</Steps>

<Aside type="note" title="访问模式">
选择私有不会修改桶权限。请在服务商控制台关闭公开入口，再验证匿名读取被拒绝。私有对象可在应用内预览、生成限时分享；有效期与实际访问能力取决于服务商实现。Typora / 命令行需要公开链接，不能使用私有目标。
</Aside>

## 如何确认成功

**图库**能看到远端文件，**资源**有发布记录。公开链接应在未登录的浏览器中显示图片；私有对象应拒绝匿名访问，并单独验证限时分享能否按时失效。连接测试通过不能代替这两项检查。

## 常见错误

| 现象 | 先检查 |
| --- | --- |
| 403 / 签名错误 | 密钥、权限、Region，以及本机时间 |
| 找不到 Bucket | 桶名与 Endpoint 是否对应同一服务和地域 |
| 无法连接 | 使用 HTTPS；本机服务可用回环 HTTP，普通局域网 HTTP 不在当前允许范围内 |
| URL 打不开 | 公开访问地址、访问策略或临时分享支持情况 |
