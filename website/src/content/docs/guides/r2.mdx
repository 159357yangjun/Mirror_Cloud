## 创建存储桶

<Steps>

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，选中自己的账户，进入 **R2 Object Storage**。首次开通按平台提示完成，先确认账户的计费与使用要求。
2. 点击 **Create bucket**，填写桶名，例如 `my-images`。按用途选择存储类别和位置后创建；记录桶名。镜云目前支持默认辖区，不支持EU/US/FedRAMP等专用辖区Endpoint。
3. 在 R2 概览或桶的 S3 API 信息中找到 **Account ID**，是32位十六进制账户编号。不要填 Bucket 名、邮箱或 Cloudflare Zone ID。

</Steps>

## 创建 S3 访问密钥

<Steps>

1. 在 R2 概览进入 **Manage API tokens / 管理 API 令牌**，创建 R2 API 令牌。
2. 权限选择 **Object Read & Write**，范围选择 **Apply to specific buckets only**，勾选刚才的桶；其他条件按实际需要设置。
3. 创建后保存 **Access Key ID** 和 **Secret Access Key** 两项，Secret通常只显示一次。它们用于S3 API；普通 Cloudflare API Token 不能替代这对密钥。

</Steps>

## 准备公开图片地址或选择私有

公开图床：打开桶 **Settings → Public access**，绑定 **Custom Domains** 下自己的域名，例如 `img.example.com`，等待状态可用。测试时也可按提示启用 **Public Development URL**，复制完整 `https://…r2.dev` 地址；开发地址有限制，不应作为长期生产地址。

私有存储：不启用公共开发地址和公开域名，检查已有公开入口是否关闭。镜云中选择私有不会替你修改桶权限。

## 在镜云逐项填写

打开 **云端 → 添加存储 → Cloudflare R2**，按四步向导操作。

| 向导 / 字段 | 从哪里取值 | 示例或规则 |
| --- | --- | --- |
| 1 · 显示名称 | 自己命名 | 我的 R2 图床 |
| 1 · Bucket | 控制台桶名 | `my-images` |
| 1 · Account ID | R2 概览/S3 API信息 | 自己的32位账户ID |
| 1 · Endpoint / Region | 根据Account ID生成 | `https://账户ID.r2.cloudflarestorage.com`；Region为`auto` |
| 2 · 发布用途 | 对外分享选“公开发布”；只在认证后访问选“私有存储目标” | 两者选一 |
| 2 · 公开访问地址 | 已启用的自定义域名或开发地址 | `https://img.example.com`，不能填S3 Endpoint |
| 3 · Access Key ID | R2令牌创建结果 | 完整复制 |
| 3 · Secret Access Key | 同次创建结果 | 完整复制，不填普通API Token |
| 3 · 资源目录 | 桶内路径前缀，可留空 | `assets`，不填URL |

在第4步核对摘要，点击 **授权测试并保存**，阅读确认后继续。保存后设为默认目标。

<Aside type="caution" title="最后一步会访问云端">
前三步只做本地字段检查；最后测试会写临时对象、读取元数据并尝试删除，清理失败可能留下对象。确认目标桶正确后再授权。
</Aside>

## 上传并确认结果

<Steps>

1. 在 **发布** 上传一张测试图，到 **图库** 刷新，再到Cloudflare桶内核对文件。
2. 公开模式：到 **资源** 复制URL，用未登录浏览器直接打开图片。
3. 私有模式：确认匿名读取被拒绝，再测试应用内认证预览或限时分享。Typora和命令行上传需要能返回公开链接的目标。

</Steps>

## 常见错误

| 现象 | 检查及处理 |
| --- | --- |
| 401/403 | 两项S3密钥是否来自同次创建、是否有对象读写权限并限定到当前桶 |
| 签名/Endpoint错误 | Account ID是否正确、Region是否auto、是否误用专用辖区 |
| NoSuchBucket | Bucket是否拼错，令牌所在账户与桶是否一致 |
| 上传成功，URL打不开 | 公共入口是否启用；公开地址是否误填成S3 API Endpoint |
| 私有模式仍可匿名读 | 检查桶的公开开发地址、自定义域名及其他代理入口；应用模式不会关闭它们 |

参考：[R2 官方 S3 入门](https://developers.cloudflare.com/r2/get-started/s3/)、[令牌](https://developers.cloudflare.com/r2/api/tokens/)、[公开访问](https://developers.cloudflare.com/r2/buckets/public-buckets/)。本网站不接收密钥。
