## 准备什么

在 Cloudflare 的 **R2 Object Storage** 创建 Bucket，记录 **Bucket 名称、Account ID**。在 R2 的 Manage API Tokens 创建仅限该桶的 **Object Read & Write** 凭据，保存 **Access Key ID、Secret Access Key**。普通 Cloudflare API Token 不能代替这对密钥。

公开图片还需要启用自定义域名；临时测试可使用 R2 公共开发地址。长期使用建议绑定自己的域名。参见 [R2 公开访问](https://developers.cloudflare.com/r2/buckets/public-buckets/)与[凭据说明](https://developers.cloudflare.com/r2/api/tokens/)。

## 在镜云填写

进入 **云端 → 添加存储 → Cloudflare R2**，按向导操作：

<Steps>
1. **存储桶**：填写显示名称、Bucket 和 Account ID。API Endpoint 自动生成，Region 保持 `auto`。当前只支持默认辖区，EU / US / FedRAMP 专用辖区暂不支持。
2. **发布用途**：公开图片选择“公开发布”，填写已启用的公开访问地址，例如 `https://img.example.com`；私有用途选择“私有存储目标”，不填公开地址。
3. **API 密钥**：填写 Access Key ID、Secret Access Key。资源目录可留空，或填 `assets`，不要填域名或完整网址。
4. **检查与保存**：核对摘要，点击“授权测试并保存”，阅读远端操作确认后继续。
</Steps>

<Aside type="caution" title="保存前需要知道">
前三步仅校验本地字段；最后的测试会写入临时对象、检查元数据并尝试删除，清理失败可能留下对象。选择私有模式不会关闭 Bucket 的公网入口，需自行在 Cloudflare 关闭并验证匿名访问被拒绝。
</Aside>

## 如何确认成功

将连接设为默认目标，在**发布**上传一张图片；到**图库**核对远端文件，再到**资源**检查结果。公开模式请用未登录的浏览器打开链接；私有模式应无法匿名读取，可在应用内预览或生成限时分享。Typora / 命令行上传需要可返回公开链接的目标。

## 常见错误

| 现象 | 先检查 |
| --- | --- |
| 401 / 403 | 密钥是否正确、是否限定到当前 Bucket、是否有对象读写与删除权限 |
| Endpoint 或签名错误 | Account ID 是否正确、Region 是否为 `auto`、是否误用了专用辖区 |
| 上传成功但链接打不开 | 公开地址是否已启用，是否误填了 S3 API Endpoint |
| 图片路径多了一层目录 | 资源目录与命名配置是否重复添加了同一目录 |

密钥只填在桌面应用中，本网站不接收密钥。
