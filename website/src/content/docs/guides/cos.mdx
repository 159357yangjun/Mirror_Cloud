## 准备什么

创建 COS Bucket，复制**完整桶名（包含 APPID 后缀）**，例如 `images-1250000000`。记录地域 Endpoint，例如 `https://cos.ap-guangzhou.myqcloud.com`；使用仅授权目标桶对象列举、读写和删除的 CAM 凭据，取得 **SecretId / SecretKey**。

准备可直接读取图片的公开域名 / CDN 地址。COS 默认桶域名格式可参考[官方域名说明](https://cloud.tencent.com/document/faq/436/56560)，能否匿名访问仍取决于读取策略。

## 在镜云填写

<Steps>
1. 进入 **云端 → 添加存储 → 腾讯云 COS**。
2. 填完整 Bucket 名、Endpoint、SecretId 和 SecretKey；资源目录可选，例如 `assets`。
3. 填写“公开访问域名”，与 API Endpoint 分开。
4. 点击 **测试并保存**，设为默认目标，再发布测试图片。
</Steps>

<Aside type="note" title="公开地址必填">
当前添加界面要求填写公开访问域名，应用不会从 Endpoint 自动推导图片地址。请先准备能读取图片的域名或 CDN，再添加连接。
</Aside>

## 如何确认成功

在**图库**核对文件，在**资源**复制链接，用未登录的浏览器确认图片能打开。

## 常见错误

| 现象 | 先检查 |
| --- | --- |
| 403 / 签名错误 | CAM 权限、SecretId / SecretKey |
| 找不到 Bucket | 桶名是否包含 APPID 后缀、Endpoint 是否与地域一致 |
| 图片打不开 | 公开读取策略、域名或 CDN 回源路径 |
