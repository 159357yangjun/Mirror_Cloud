## 创建 Bucket 并记录地域

<Steps>

1. 登录 [OSS控制台](https://oss.console.aliyun.com/)，进入Bucket列表，创建存储桶。名称例如 `my-images`；地域选择离主要使用者较近的位置，记录地域ID。
2. 存储类别和冗余按实际用途选择。访问权限先保留私有；确定要公开的测试图片，再单独配置公开只读或通过受控CDN提供图片。不要选择公共读写。
3. 在桶的概览/访问端口中复制该地域的**外网Endpoint**。杭州示例为 `oss-cn-hangzhou.aliyuncs.com`，镜云中加上 `https://`。不要选带 `-internal` 的内网地址，也不要在Endpoint前再拼桶名。

</Steps>

## 准备 RAM 用户和密钥

<Steps>

1. 到 [RAM控制台](https://ram.console.aliyun.com/)，为镜云建立专用RAM用户，按当前控制台流程创建长期AccessKey。
2. 给该用户授予目标桶所需的列举、读取、写入、删除权限。限制资源到目标桶；不要为了方便授予整个阿里云账号的管理权限。
3. 保存同一对 **AccessKey ID / AccessKey Secret**。镜云当前表单没有STS Security Token字段，不能只填临时三元组中的两项。

</Steps>

## 配好图片访问域名

镜云的OSS添加界面要求**公开访问域名必填**。在桶的域名管理中绑定自己的域名，按控制台指引配置DNS/CNAME与HTTPS；也可使用已正确配置回源的CDN域名。公开读取只开放必要图片，不要公开整个私人文件库。

阿里云默认OSS域名对图片等内容可能强制下载，做文档外链应使用已验证能直接显示图片的自定义域名。**尚无可用图片域名时，先完成这一步，再添加镜云连接。**

## 在镜云逐项填写

打开 **云端 → 添加存储 → 阿里云 OSS**。

<ConfigurationFields provider="oss" />

点击 **测试并保存**；它验证存储接口操作，不替你配置DNS/CDN或开放读取。保存后设为默认发布目标。

## 上传并确认结果

<Steps>

1. 在 **发布** 上传一张测试图；到 **图库** 刷新，并在OSS控制台核对对象路径。
2. 到 **资源** 复制URL，例如图片在 `assets/test.jpg`，图片地址应对应域名下同一路径，避免CDN重复添加 `assets`。
3. 用未登录浏览器打开；应显示图片，不能要求登录、返回XML错误或只打开管理后台。

</Steps>

## 常见错误

| 现象 | 检查及处理 |
| --- | --- |
| 403 / AccessDenied | RAM用户权限、桶Policy/ACL、密钥是否启用；用最小范围补足缺少的操作 |
| NoSuchBucket / 地域错误 | 桶名和Endpoint地域是否一致，是否误用内网Endpoint |
| 能上传但图片打不开 | 检查域名绑定、HTTPS证书、DNS/CDN回源和对象读取策略 |
| 浏览器只下载不预览 | 核对是否还在用默认OSS域名；按官方说明配置自定义域名 |
| 签名失败 | ID/Secret是否配对、是否多空格、本机时间是否准确 |

参考：[OSS地域与Endpoint](https://help.aliyun.com/zh/oss/user-guide/regions-and-endpoints)、[OSS权限概述](https://help.aliyun.com/zh/oss/user-guide/overview-75/)、[RAM AccessKey](https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair)。本网站不接收密钥。
