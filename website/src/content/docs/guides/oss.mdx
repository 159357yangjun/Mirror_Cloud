## 准备什么

在 OSS 创建 Bucket，记录桶名和所在地域的外网 Endpoint，例如 `https://oss-cn-hangzhou.aliyuncs.com`。使用仅授权目标桶对象读写、列举与删除的 RAM 凭据，取得 **AccessKey ID / AccessKey Secret**。

另准备实际可访问图片的域名或 CDN 地址，例如 `https://img.example.com`。Endpoint 用于调用存储 API，公开地址用于打开图片。参见 [OSS Endpoint](https://www.alibabacloud.com/help/en/oss/user-guide/regions-and-endpoints)与[域名说明](https://www.alibabacloud.com/help/en/oss/user-guide/access-oss-via-bucket-domain-name)。

## 在镜云填写

<Steps>
1. 进入 **云端 → 添加存储 → 阿里云 OSS**。
2. 填 Bucket、Endpoint、AccessKey 和 Secret；资源目录可留空或填 `assets`。
3. 填写“公开访问域名”，不要用控制台地址代替。
4. 点击 **测试并保存**，设为默认目标，发布一张图片。
</Steps>

<Aside type="note" title="公开地址必填">
当前添加界面要求填写公开访问域名，应用不会从 Endpoint 自动推导图片地址。请先准备能读取图片的域名或 CDN，再添加连接。
</Aside>

## 如何确认成功

在**图库**核对远端文件，在**资源**复制链接，并用未登录的浏览器打开图片。

## 常见错误

| 现象 | 先检查 |
| --- | --- |
| 403 | RAM 权限、AccessKey 是否有效 |
| 找不到 Bucket / 地域错误 | Bucket 与 Endpoint 是否同地域 |
| 上传成功但打不开 | 公开域名、CDN 回源和读取策略 |
