## 先确认是否适合当前用途

WebDAV只是文件访问协议，不等于公开图床。镜云当前WebDAV添加界面要求**公开访问域名必填**；如果只有一个需要登录的网盘地址，尚不能直接用它向文档读者提供图片。先让服务管理员准备独立静态图片域名或公开代理，再添加连接。

## 从服务端取得四项信息

<Steps>

1. 在NAS、自建网盘或服务商控制台启用WebDAV，确认账号有目标目录的列举、读取、写入和删除权限。
2. 从该服务的WebDAV连接说明复制**完整HTTPS Endpoint**。这是接口地址，不是浏览器打开的管理后台。
3. 取得用户名和专用 **App Password / 应用密码**。启用双因素验证的服务通常不能直接使用网页登录密码。
4. 先用该服务推荐的客户端验证账号能访问目标目录，再确认独立图片域名能匿名读取同一文件。

</Steps>

例如Nextcloud：登录后进入**文件 → 设置**，复制WebDAV地址；常见格式是 `https://cloud.example.com/remote.php/dav/files/用户名/`。应用密码通常在**个人设置 → 安全**中创建。其他服务路径可能不同，不能直接照抄Nextcloud格式。

## 在镜云逐项填写

打开 **云端 → 添加存储 → WebDAV**。

<ConfigurationFields provider="webdav" />

公开地址需要与Endpoint及资源目录的真实映射一致。例如资源目录为 `images`，应用生成的图片URL会包含这层目录；公开代理不能再重复拼一次。不要填写需要Cookie、Basic Auth或交互登录的地址。

<Aside type="note" title="HTTPS与本机例外">
远程服务使用HTTPS。仅同一台电脑上的回环服务可用HTTP，例如127.0.0.1；普通局域网HTTP地址不在当前允许范围内。不要将公网访问地址指向仅自己电脑可达的回环地址。
</Aside>

## 保存、上传和验证

<Steps>

1. 点击 **测试并保存**，成功后在 **图库** 刷新，确认能列出目标目录。
2. 设为默认发布目标，上传一张测试图；在NAS/网盘中确认文件确实存在。
3. 到 **资源** 复制URL，用未登录的浏览器打开。直接显示图片才算外链可用；跳到登录页不算通过。

</Steps>

## 常见错误

| 现象 | 检查及处理 |
| --- | --- |
| 401 | 用户名、应用密码、服务是否要求专用应用密码 |
| 403 | 目录权限是否允许列举/写入/删除；只读账号不能完成发布 |
| 404 / 无法列举 | Endpoint是否缺少WebDAV路径，资源目录是否多拼一层 |
| HTTPS证书错误 | 由服务管理员修复域名/证书链，不要关闭证书校验 |
| 文件已上传但URL要求登录 | 公开地址实际仍是认证Endpoint；需另配静态域名/代理 |
| 公开地址不知道填什么 | 向服务管理员索取“无需登录就能打开图片的根URL”；尚无此入口时先别保存 |

参考：[Nextcloud官方WebDAV连接](https://docs.nextcloud.com/server/latest/user_manual/en/files/access_webdav.html)、[应用密码与设备管理](https://docs.nextcloud.com/server/latest/user_manual/en/session_management.html)。其他NAS/服务以其官方连接说明为准；本网站不接收密码。
