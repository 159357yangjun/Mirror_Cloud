## 准备什么

在 NAS 或自建服务开启 WebDAV，准备 **Endpoint、用户名、密码 / App Password**。账号应能列举、读取、写入并删除目标目录内的文件。使用 HTTPS；本机服务可用回环 HTTP，普通局域网 HTTP 不在当前允许范围内。

## 在镜云填写

<Steps>
1. 进入 **云端 → 添加存储 → WebDAV**。
2. 填 Endpoint、用户名、密码，资源目录可选，例如 `images`。
3. 填写真正可直接读取图片的“公开访问域名”，当前添加界面要求此项必填。
4. 点击 **测试并保存**；到**图库**验证远端浏览，再发布一张测试图片。
</Steps>

<Aside type="caution" title="WebDAV 地址通常需要登录">
需要账号、Cookie 或 Basic Auth 的 Endpoint 不能直接当公开图片地址。应另外提供静态文件域名 / 代理；尚无公开图片地址时，当前界面无法保存该连接，请先配置访问入口。
</Aside>

## 如何确认成功

文件确实出现在目标目录中；若配置公开发布，用未登录的浏览器打开资源链接，确认不要求登录。

## 常见错误

| 现象 | 先检查 |
| --- | --- |
| 401 / 403 | 用户名、密码 / App Password、目录权限 |
| 404 / 无法列举 | Endpoint 是否包含服务要求的 WebDAV 路径、资源目录是否正确 |
| 链接要求登录 | 填成了 WebDAV Endpoint，需要独立公开图片地址 |
