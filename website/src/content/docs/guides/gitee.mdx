## 准备什么

准备 Gitee 资源仓库，确认实际分支（可能是 `master` 或 `main`），创建具备目标仓库内容读写权限的访问令牌。

## 在镜云填写

<Steps>
1. 进入 **云端 → 添加存储 → Gitee**。
2. 填 Owner、Repository、Branch 和 Token。Repository 只填仓库名，资源目录可填 `assets`。
3. 没有独立公开域名时留空该项；应用生成 `https://gitee.com/Owner/Repository/raw/Branch/目录/文件`。
4. 点击 **测试并保存**，设为默认目标，再上传测试图片。
</Steps>

<Aside type="note" title="公开访问要单独验证">
Raw 地址能否被访客打开取决于仓库公开性及平台访问限制。若受限，可配置自己的公开代理，或让 Gitee 只保存多云副本，由对象存储提供公开链接。
</Aside>

## 如何确认成功

在**图库**刷新文件，核对仓库提交；用未登录浏览器打开**资源**里的链接。

## 常见错误

| 现象 | 先检查 |
| --- | --- |
| 鉴权失败 | Token 是否有效、是否有仓库读写权限 |
| 找不到文件 / 分支 | Owner、仓库名与实际分支 |
| Raw 无法匿名访问 | 仓库公开性、平台限制；需要时改用独立公开地址 |
