## 先准备仓库

<Steps>
1. 登录 [Gitee](https://gitee.com/)，点击右上角 **＋ → 新建仓库**。仓库名称可写“我的图床”，**路径**例如 `my-images`；镜云使用的是路径，不是中文显示名称。
2. 需要给文档读者直接看图时，选择公开仓库。勾选初始化 README，再创建；初始化后才有可用分支。若使用已有仓库，不必新建。
3. 打开仓库首页。地址如 `https://gitee.com/your-name/my-images`，记下 `your-name` 和 `my-images`。从文件列表上方的分支菜单复制实际分支名，例如 `master`；不要凭印象填 `main`。
</Steps>

## 创建访问令牌

<Steps>
1. 点击头像 → **设置 → 私人令牌**，或打开 [私人令牌页面](https://gitee.com/profile/personal_access_tokens)。
2. 选择生成新令牌，描述填“镜云图床”，设置过期时间，授予仓库 API 所需的 `projects` 权限；部分旧界面将仓库权限显示为 `project`。以当前页面的“仓库”权限说明为准，不勾无关管理权限。
3. 提交后按提示完成身份验证，复制令牌。令牌只填入镜云的“访问令牌”，不是登录密码，也不是 SSH 公钥。离开后若不能再次查看，需重新生成。
</Steps>

## 上传并确认结果

<Steps>
1. 在 **发布** 上传一张不含隐私的测试图，等任务成功。
2. 到 Gitee 仓库查看 `assets` 目录，确认出现图片和新的提交；到镜云 **图库** 刷新确认文件。
3. 到 **资源** 复制 URL，在未登录 Gitee 的浏览器或无痕窗口打开。能直接显示图片才说明公开访问可用。
</Steps>

<Aside type="caution" title="上传成功，但 Gitee 图片打不开？">
Gitee Raw 地址受仓库公开性和平台访问限制影响，不能保证可作为长期外链。无需为此反复更换有效令牌；先检查匿名访问。若平台拦截外链，可让 Gitee 保存备份，使用 R2/OSS/COS 提供公开图片地址；私有仓库不会因为镜云生成了 URL 就变公开。
</Aside>

## 常见错误

| 现象 | 检查及处理 |
| --- | --- |
| 401 / 令牌无效 | 检查有效期、是否被撤销、有无多余空格；重新生成后只在应用里替换 |
| 403 / 无写权限 | 确认令牌有仓库权限、账号能向该仓库写入，以及分支是否受保护 |
| 404 / 找不到分支 | 直接打开仓库网址核对Owner/路径；空仓库先初始化，分支以菜单为准 |
| 文件已上传，但链接要求登录 | 核对仓库公开性；私有仓库需要独立公开代理或其他公开目标 |
| 公开仓库仍无法外链 | 分别测试 Gitee 网页和 Raw 链接；平台限制不能靠镜云连接测试消除 |

参考：[Gitee 令牌入口](https://gitee.com/profile/personal_access_tokens)、[Gitee 官方令牌申请说明](https://help.gitee.com/repository/settings/sync-between-gitee-github)。控制台入口可能调整，以当前页面为准。本网站不接收令牌。
