## 准备什么

准备一个资源仓库，确认已有目标分支，例如 `main`。创建仅授权该仓库、具备 **Contents: Read and write** 权限的细粒度 Token。

## 在镜云填写

<Steps>
1. 进入 **云端 → 添加存储 → GitHub**。
2. Owner 填用户或组织名；Repository 只填仓库名，不填完整网址；Branch 填实际分支。
3. 填 Token，资源目录可填 `assets`，首次上传会自动创建目录。
4. 公开仓库可留空“自定义公开域名”，应用会生成 Raw URL；有自己的代理 / CDN 才填写。
5. 点击 **测试并保存**，设为默认目标，再发布一张图片。
</Steps>

<Aside type="caution" title="仓库公开性">
私有仓库的 Raw 地址不能直接供访客读取。需要自己的公开代理 / CDN，或改用对象存储作为公开目标。仓库适合文档和少量资源，不适合承担大量图片流量。
</Aside>

## 如何确认成功

**图库**能列出远端文件，仓库中出现提交；**资源**中的链接能在未登录浏览器中打开。

## 常见错误

| 现象 | 先检查 |
| --- | --- |
| 401 | Token 是否过期、撤销或复制错误 |
| 403 | Token 是否获准访问目标仓库，并有 Contents 写权限 |
| 404 | Owner、仓库名、分支，以及私有仓库授权 |
| 409 | 同一分支有并发写入；应用会重读远端状态后重试，仍失败时稍后重试 |
