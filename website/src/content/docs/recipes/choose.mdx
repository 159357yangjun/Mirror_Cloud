## 设置方法

先用默认设置上传一张图片，确认任务成功和链接可用，再调整缩放、输出格式、质量或命名。普通上传无需先创建方案。

## 按用途选择

| 用途 | 建议 |
| --- | --- |
| 文档截图 | 保证文字清晰，避免过度缩小和压缩 |
| 博客配图 | 适当缩小尺寸，可选择 WebP |
| 分享图片 | 控制文件体积，上传后检查清晰度 |
| 原图归档 | 保留原格式，避免有损转换 |

修改后上传一张测试图，检查尺寸、格式和链接。没有特殊要求时保留默认值。

多云副本在 **云端** 配置；插件在 **插件** 页面管理。插件失败不会把已成功上传的图片回滚。
