当前正式版为 **1.4.13**；安装文件来自 [官方 Release](https://github.com/159357yangjun/Mirror_Cloud/releases/latest)。候选构建用于验收，不会通过正式更新检查推送。1.4.14 的更新提示缓存修复正在候选验证，尚未正式发布。

## 更新步骤

1. 备份重要数据。应用内的 **设置 → 关于与诊断 → 打开数据目录**可定位本地索引；系统凭据与个人壁纸另存在本机，不属于单独的 SQLite 文件备份。
2. 打开 **设置 → 版本与更新**，点击 **检查更新**，核对当前版本与目标正式版本。
3. 有更新时点击 **下载更新**，等待发布签名和 SHA256 校验通过。
4. 点击 **立即安装 → 安装并退出**。应用退出并启动安装器；完成后重新打开镜云。
5. 核对版本、资源、云端连接、默认目标、插件、主题和壁纸，再上传一张测试图。使用 Typora 时也检查桥接是否正常。

同版本显示“暂无更新”属于正常结果。网络不可达或校验失败时保留当前应用，稍后重试，不运行来历不明或验证失败的安装文件。

## 签名与哈希分别验证什么

SHA256 检查下载内容是否完整；Ed25519 签名用于核对发布来源。客户端使用编译进程序的公钥，不从待验安装包临时获取信任公钥。检查、下载和安装前分别核验，最终安装前还会重新读取磁盘文件并计算哈希。

正式 Release 同时提供 EXE、MSI、源码 ZIP、`SHA256SUMS.txt`、`update-manifest.json` 和对应签名。请保留校验文件与正确版本一起核对，不混用候选和正式包的哈希。

## 旧版本与升级后的提示

没有签名校验能力的旧客户端不能仅靠服务器新增签名文件获得验签能力。可先通过可信公钥独立核验正式包后手动安装，再使用新客户端的签名更新流程。

1.4.13 升级后可能暂时保留旧版本的检查卡片和侧栏提醒；手动点一次 **检查更新**，成功后重新打开应用即可清除。此显示问题不代表尚未升级；以实际程序版本和新检查结果核对。源码修正将随下一补丁发布，不会替换已有正式标签。

发布签名不等同于 Windows Authenticode；也不能保证网络始终可达或云端图片链接始终有效。
