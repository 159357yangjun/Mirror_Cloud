本文说明镜云桌面应用与官网各自会处理哪些数据，以及数据会发送到哪里。镜云没有自己的图片托管后端；图片存储在用户配置的云服务中。

## 桌面应用

### 本机保存

- Provider 连接信息、资源索引、任务状态和应用设置保存在本机应用数据目录。
- Token、Secret Key 和密码由操作系统凭据库保护；普通 SQLite 配置保存凭据引用，不保存这些秘密的明文。
- 个人壁纸保存在本机外观数据中。

### 更新检查

应用启动时读取本机缓存的检查结果；没有有效缓存时会连接 GitHub 获取公开的更新清单。缓存目前最长有效 24 小时。用户也可以在“设置 → 版本与更新”主动检查。请求不包含图片、云存储凭据或个人文件；GitHub 作为服务提供方会接收到常规网络连接信息，例如 IP 地址和客户端请求信息。下载更新包只在用户选择下载时发生。

### 用户配置的云服务

上传、浏览、下载、移动、重命名或删除云端文件等操作会把完成该操作所需的数据发送到用户选择并配置的 Provider。上传图片会把图片内容发送到目标存储服务；其他操作可能发送路径、文件名、对象元数据或凭据。Mirror Cloud 项目运营者不会代收这些图片或凭据。云服务自身如何处理数据，受用户与对应服务商的设置及隐私条款约束。

### 插件与集成

只有用户安装、启用并配置的插件或集成才参与相应操作。Webhook 插件可能向用户填写的 HTTPS endpoint 发送资源事件；AI 插件会向用户配置的模型服务发送本次请求需要的提示内容。插件处理的数据取决于其功能、配置和已授予权限。启用前应检查目标地址和服务商政策；撤销权限或停用插件后，镜云不再按该配置调用插件。

Typora、本机 HTTP API、快捷键和右键菜单是本地集成入口。它们不会把图片发送给 Mirror Cloud 运营者；实际云端传输遵循上文 Provider 与插件规则。

## 网站与在线演示

教程网站发布在 GitHub Pages。浏览网站时，GitHub 作为托管服务可能处理常规访问日志。在线演示站由第三方 Wix 托管，只使用模拟数据，不连接用户的真实云存储。访问这些网站时也适用相应托管服务商的隐私条款。

请勿在在线演示中输入真实云存储凭据，也不要把包含密钥、Token 或个人图片的日志、截图提交到公开仓库或 Issue。

## 诊断与联系

反馈问题时，请先删除日志和截图中的 Token、Secret、密码、私有地址及个人图片。项目公开 Issue 会对公众可见。镜云不要求用户把真实数据库或云凭据上传到 GitHub Actions。

本说明随应用网络功能变化而更新。若你发现与当前版本行为不符，请通过[项目 Issues](https://github.com/159357yangjun/Mirror_Cloud/issues)报告，并避免附上秘密信息。
