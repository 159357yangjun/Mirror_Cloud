## 密钥怎么保存

Token、Secret Key 和 WebDAV 密码进入操作系统凭据库；SQLite 保存连接配置、资源索引、任务状态和凭据引用。本教程网站不接收密钥。截图、报错和公开仓库中都不要包含密钥。

## 公开与私有

- **公开图片**：拿到链接的人可能读取图片；请用未登录浏览器验证实际访问。
- **R2 / S3 私有模式**：仅记录访问意图，不会自动修改桶权限。应在服务商关闭公开入口，并验证匿名读取被拒绝。
- **限时分享**：链接持有者可在有效期内访问，不需要其持有存储密钥。当前不能逐链接撤销，生成前确认范围和有效期；到期行为仍需按服务商实际验证。

## 使用边界

删除仍被资源副本、多云组或处理链引用的连接时，应用会拒绝。先处理引用，避免丢失访问入口。

URL 导入只接受 HTTP / HTTPS 图片，并限制下载大小和时间。存储与集成地址使用 HTTPS，本机回环服务可使用 HTTP。

本机 API 的 Token 也属于密钥；泄漏后到**设置**重置，旧值立即失效。个人壁纸另存于本机外观存储，清除壁纸不会删除资源或云端文件。
