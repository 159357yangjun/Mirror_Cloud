从正式 **1.4.13** 起，镜云支持本地 JSON Manifest 安装、宿主兼容版本检查和自动配置表单。更早版本请先[升级](../updates/)。文件是供镜云内置能力使用的声明，不是可执行脚本或 WASM。

## 从文件安装

1. 从可信作者获取 UTF-8 JSON Manifest。可先下载仓库中的 [Markdown 模板示例](https://github.com/159357yangjun/Mirror_Cloud/blob/v1.4.13/examples/plugins/markdown-card.plugin.json) 练习。
2. 打开桌面应用的 **插件 → 从文件安装**，选择 JSON 文件。
3. 核对预览中的名称、ID、插件版本、宿主 API / Schema、声明权限和触发器。取消不会安装。
4. 点击 **安装并保持关闭**。新插件默认关闭，仅获得基础资源读取权限。

文件最大 256 KiB，API 与 Schema 当前都必须为 **1**。插件自己的版本与宿主版本分别校验。本地 ID 不能使用 `official` 或 `official.*`，已有同 ID 插件不会被覆盖。

预览有效期为五分钟；过期后重新选择文件。安装使用预览时的内容，预览后修改原文件不会改变即将安装的声明。

## 配置并开启

在已安装插件卡片点击 **配置**，按表单填写文本、地址、开关、数字或枚举，再点击 **保存配置**。表单会检查必填项、类型、长度和数值范围；关闭状态可保存未完成草稿，开启前必须补齐。

地址使用 HTTPS，只有本机回环服务可使用 HTTP；地址中不要内嵌账号或密码。AI API Key 在 **插件 → AI 配置**中保存到系统凭据库，不填入普通插件配置或 Manifest。

开启需要网络、密钥或外部写入的插件时，应用会单独请求授权。确认用途后再允许；点击 **不开启**不会授予这些权限。需要停用时关闭开关，或点击 **撤销敏感授权**，撤销也会停用插件。

## 选择触发器与查看结果

只启用你需要的触发器，例如 **上传后**或**手动执行**。权限、触发器和运行开关分别控制；勾选触发器不会自动授予权限。

Desktop、Typora 桥接和本机 API 共用保存的配置与授权。执行结果可在 **插件 → 执行记录**中查看；插件失败只记录提示，不会把已经上传成功的图片改为上传失败。

## 常见问题

| 提示或现象 | 处理 |
| --- | --- |
| 预览失败 | 检查 JSON 格式、文件大小、API / Schema 版本、ID 是否重复或使用官方前缀 |
| 预览已过期 | 重新选择文件并核对预览 |
| 保存按钮不可用 | 按字段旁提示修改地址、类型或范围 |
| 草稿可保存但不能开启 | 补齐必填字段，再确认所需权限 |
| 历史配置有未声明字段 | 表单不显示字段内容；确认是否移除后再保存，未保存前原数据保留 |
| 升级后旧官方插件仍关闭 | 原开关与授权保留，按需手动开启，不自动增加敏感权限 |

社区索引、自动更新插件包和 WASM 运行时目前尚未提供。
