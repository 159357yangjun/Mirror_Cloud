## 开始前

镜云需正在运行，已连接可写云端并设置能返回公开链接的默认目标。请求使用与桌面相同的处理链；Token 和现成示例在**设置 → Local HTTP API**中复制。重置 Token 后，旧值立即失效。

| 项目 | 当前行为 |
| --- | --- |
| 地址 | `http://127.0.0.1:36677`，仅本机回环，端口不可配置 |
| 启动 | 随应用启动，目前没有独立关闭开关 |
| 鉴权 | 除健康检查外，使用 `Authorization: Bearer <token>` |
| 限制 | 请求体最多 32 MiB，路径上传每次 1–100 个 |
| 响应 | JSON；关闭连接，不缓存 |

## 1. 检查服务

```powershell
Invoke-RestMethod 'http://127.0.0.1:36677/health'
```

正常返回 `ok: true`，服务名为 `Multi-cloud Publisher`，API 版本为 `v1`。不需要 Token。

## 2. 上传本机文件路径

将下例 Token 和文件路径换成自己的值，在 PowerShell 执行：

```powershell
$token = '<从设置复制的 Token>'
$headers = @{ Authorization = "Bearer $token" }
$body = @{ paths = @('C:/Users/you/Pictures/screenshot.png') } | ConvertTo-Json -Compress
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:36677/v1/upload-paths' `
  -Headers $headers -ContentType 'application/json' -Body $body
```

成功响应：

```json
{ "ok": true, "urls": ["https://img.example.com/screenshot.png"] }
```

## 3. 直接上传图片字节

适合 ShareX 等集成。用上面的 `$token`，请求体为原始图片，不使用表单：

```powershell
curl.exe -s -X POST 'http://127.0.0.1:36677/v1/upload' `
  -H "Authorization: Bearer $token" `
  -H 'X-Publisher-Filename: capture.png' `
  --data-binary '@C:/Users/you/Pictures/screenshot.png'
```

文件名头可省略，默认 `upload.png`。返回格式相同，从 `urls` 数组获取链接；本机 API 不触发桌面“发布后自动复制”。

## 排错

| 结果 | 检查 |
| --- | --- |
| 连接失败 | 应用是否运行、36677 是否被占用；设置中可查看服务状态 |
| 400 | 路径数组是否为 1–100 条 |
| 401 | Token 是否正确，是否刚被重置 |
| 404 / 405 | 路径或请求方法错误；上传接口必须 POST |
| 422 | 发布失败，读取 `error`，到**任务**检查默认目标与凭据 |
| 有链接但打不开 | 公开访问地址或图床读取策略 |

<Aside type="caution" title="超限时会直接断开">
请求体超过 32 MiB、头部超过 64 KiB 或请求行无法解析时，服务直接关闭连接，没有 413 响应。请在发送前控制大小。
</Aside>

## 集成注意

- 仅供本机脚本和原生应用使用；不提供 CORS / OPTIONS，网页脚本无法直接跨域调用。
- 每次响应关闭连接，调用方不要复用长连接。界面状态约 1.5–2.5 秒后刷新，以接口响应为准。
- URL 由服务端发布结果返回；返回成功仍需单独核对实际公开访问。不要将 Token 写入公开脚本、截图或日志。
