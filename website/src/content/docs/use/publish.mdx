## 开始前

先在**云端**添加连接并测试保存，将单个连接或多云组设为默认目标。应用维护默认处理链，无需先创建方案。

## 发布步骤

<Steps>
1. 进入 **发布**，或点击“快速发布”。
2. 选择来源：本地文件可拖入或选择多张；图片 URL 每行一条；剪贴板需先复制截图或位图。
3. 核对图片、发布目标和处理设置，提交上传。URL 图片会先下载，再按同一处理链缩放、转换或命名。
4. 在**任务**确认结果，在**图库**核对真实文件，在**资源**复制 URL、Markdown 或 HTML。
</Steps>

## 公开与私有

- **公开目标**：复制链接后，用未登录浏览器验证图片能打开。上传成功不代表域名配置正确。
- **R2 / S3 私有目标**：不产生永久公开 URL，在应用内预览或按需生成限时分享。Typora / 命令行上传需要公开目标。
- **多云部分失败**：查看各副本状态，保留健康副本后再执行修复，不要重复上传来碰运气。

## 遇到问题

没有目标时先设置默认云端；上传失败看**任务**中的原因；链接打不开检查公开地址与读取策略。粘贴无反应时，确认复制的是图片内容而非文字路径。

## 换一张个人壁纸

点击侧栏皮肤入口，选择内置天空，或“导入本机图片”（PNG / JPG / WebP，最大 16 MB）。导入会生成缩小副本，只保存在本机，不上传，也不修改原图。可“不使用壁纸”、“清除个人图片”或“恢复默认”；壁纸不参与图片发布。
