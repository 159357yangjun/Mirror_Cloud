查看 [v1.4.15 发行说明及全部发布文件](https://github.com/159357yangjun/Mirror_Cloud/releases/tag/v1.4.15)。请从 GitHub 正式 Release 获取安装文件；不要把候选构建、在线体验或未经验证的镜像当作正式安装包。

下载后，请按 Release 提供的 `SHA256SUMS.txt` 检查对应文件的完整性；版本更新与签名校验说明见 [版本与签名更新](../updates/)。

## 浏览器在线体验

[打开镜云在线体验（无需登录）](https://headless-ftmdatbupdr-yjun9573-1408.wix-site-host.com/)

在线体验展示上传、上传记录、云端配置、云端文件、插件、任务和设置等操作流程，使用浏览器本地模拟数据。**不会连接真实云端，也不会生成可用的真实图片公开链接**。请勿在演示网站中输入云存储密钥或任何个人凭据。

若要真正上传图片、管理远端文件、使用 Windows 快捷键、右键菜单或本机 HTTP API，请安装上方 Windows 正式版，并从 [云端配置教程](../../guides/r2/) 开始。
